# NotificationLog 1.0.0

Локальный журнал уведомлений Android для Xiaomi 13T Pro / HyperOS.

## Реализовано

- NotificationListenerService
- Системные и сторонние уведомления
- Новые уведомления, изменения и удаления
- Каждое изменение сохраняется отдельной версией
- Сохранение основных полей Notification
- Рекурсивная сериализация `Notification.extras` в JSON
- SHA-256 состояния уведомления
- Room / SQLite
- Ротация истории в днях
- Ежедневная очистка через WorkManager
- Проверка Notification Access
- Работа без INTERNET permission
- UI на Jetpack Compose / Material 3
- Главный экран со статистикой
- Поиск по приложению и тексту уведомления
- Фильтры: все / новые / изменения / удалённые
- Временная лента истории конкретного уведомления
- Настройки срока хранения
- Полная очистка истории

## Сборка

### GitHub Actions

В проект уже добавлен workflow `.github/workflows/build-apk.yml`. Он автоматически устанавливает JDK 17 и Android SDK 35, запускает Gradle 8.9 и собирает `app-debug.apk`.

Подробная инструкция находится в `GITHUB_BUILD.md`.

### Android Studio

Открыть каталог проекта в Android Studio с установленным Android SDK 35 и выполнить `assembleDebug`.

APK появится в:

`app/build/outputs/apk/debug/app-debug.apk`

## Первое включение

1. Установить APK.
2. Открыть приложение.
3. Нажать «Включить» в блоке доступа к уведомлениям.
4. Разрешить Notification Access для «Лог уведомлений».
5. На Xiaomi/HyperOS рекомендуется разрешить автозапуск приложения и снять ограничения энергосбережения, если система ограничивает работу NotificationListenerService.

## Приватность

Приложение не содержит сетевого разрешения `INTERNET`. Уведомления и их история сохраняются локально в SQLite.
